# Architecture Decision Records

Short documents capturing *why* a significant decision was made, so that in eighteen months
nobody has to reconstruct the reasoning from the code.

Write one when a decision is expensive to reverse, constrains future options, or will otherwise
be questioned later. Do not write one for routine choices.
